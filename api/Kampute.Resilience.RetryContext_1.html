    Definition

    Describes a failed attempt of an operation that returns a value, and the delay before the operation is retried.
    public readonly struct RetryContext<T>
    Inheritance
    • object
    • ValueType
    • RetryContext<T>

    Type Parameters

    T
    The type returned by the operation.

    Remarks

    RetryPolicy<T> passes this value to its delay override and retry handlers. An attempt fails either by throwing an exception that the policy retries or by returning a result that the policy retries; HasResult tells them apart.
