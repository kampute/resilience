    A lightweight, dependency-free .NET library for retrying operations that fail transiently. Compose constant, linear, Fibonacci or exponential backoff with retry limits, elapsed-time limits, delay caps and jitter; build immutable, fluent retry policies that choose which exceptions and returned results to retry and hook into each retry; and run synchronous or asynchronous operations with little overhead. Retry sessions support retry loops that you write yourself.

    Namespaces

    Kampute.ResilienceThis namespace provides retry strategies, retry policies that run operations with retries, and retry sessions for retry loops that you write yourself.
    Kampute.Resilience.StrategiesThis namespace contains the built-in retry strategies, which compute the delay before each retry attempt.
    Kampute.Resilience.Strategies.ModifiersThis namespace provides modifiers that can be applied to retry strategies to alter their behavior.
